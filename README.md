# Deutsch: Von Null bis C1

Односторінковий тренажер німецької для україномовних: 100 днів-уроків, 2000 слів
із транскрипцією, 75 правил граматики і 12 типів вправ. Увесь застосунок — один
файл `index.html` без збірки й без залежностей.

## Що всередині

| Вкладка | Що робить |
|---|---|
| **Шлях** | 100 днів у вигляді доріжки: A1→C1, по 20 днів на рівень. День відкривається після попереднього; перший день кожного рівня відкритий одразу |
| **Слова** | 2000 слів у 100 темах, з артиклем, множиною, транскрипцією й озвучкою |
| **Правила** | 75 правил із прикладами, транскрипцією прикладів і таблицею відмінків |
| **Тренажер** | ті самі 12 типів вправ, але без сердець і без обмежень |
| **Профіль** | статистика, 9 досягнень, маршрут рівнів, розрахунок часу |

## День = тема

Один день — це одна тема з 20 слів. 20 тем на рівень × 5 рівнів = 100 днів, 2000 слів.
До дня прив'язані: правило граматики (15 із 20 днів мають нове правило, решта —
дні закріплення), пошукове посилання на YouTube за темою, і урок із 14 вправ,
які генеруються зі слів саме цього дня.

## 12 типів вправ

`artikel` der/die/das · `uk_de` переклад з української · `de_uk` переклад на українську ·
`audio` слово на слух · `type` впиши слово · `plural` форма множини · `pairs` пари ·
`build` збери речення · `gap` пропуск (відмінки, прийменники, форми) ·
`listen` речення на слух · `artpl` артикль множини · `dictate` диктант.

Аудіо-вправи використовують `SpeechSynthesis` браузера з німецьким голосом; якщо
голосу немає, ці типи автоматично зникають зі списку (`EX[k].need(d)`).

## Ігрова частина

XP (1 за відповідь, +10 за урок, +10 за 100% влучності), денна ціль 30 XP,
серія днів, 5 сердець на урок, корони за повторне проходження дня (до 3),
звуки на Web Audio, конфеті й **Вальді** — такса-маскот у нашийнику кольорів прапора.
Прогрес — у `localStorage` під ключем `de-c1-v3`.

## Збірка

`index.html` збирається з частин у `parts/`:

```bash
python3 build.py
```

| Файл | Що це |
|---|---|
| `parts/style.css` | уся верстка |
| `parts/body.html` | розмітка |
| `parts/vocab.js` | **згенерований** — не редагувати руками |
| `parts/vocab_new_*.js` + `parts/vocab_fill.py` | джерела нових слів |
| `parts/_vocab_old.js` | 1000 слів попередньої версії |
| `parts/build_vocab.py` | зшиває словник і прибирає дублікати |
| `parts/_grammar_old.js` | 75 правил |
| `parts/sentences.js` | 150 речень для «збери речення» |
| `parts/gaps.js` | 100 вправ із пропусками |
| `parts/videos.js` | 100 тем відео |
| `parts/app1.js` | маскот, транскрипція, дані, стан, звук |
| `parts/app2.js` | генератори вправ і двигун уроку |
| `parts/app3.js` | вкладки й рендеринг |

### Формат словника

`німецьке слово|множина|український переклад`, теми розділені комами, слова — `;`.

Позначки множини: `—` немає множини · `-` форма не змінюється · `-n`, `-e`, `-er`, `-s`
додати закінчення · `¨` умлаут кореневої голосної · `Daten` готова форма.
Розбирає це `plForm()` в `app2.js`.

`build_vocab.py` гарантує 400 унікальних слів на рівень: якщо нове слово вже є в
старому наборі, воно викидається, а тема добирається з пулу `vocab_fill.py`.
Якщо пулу забракне — скрипт надрукує `STILL SHORT` і назве тему.

## Дві деталі реалізації

**Транскрипція без артикля.** У вправі «який артикль?» під словом стоїть
`trBare()`, а не `tr()`: `tr("die Aktie")` дало б «ді акті» й видало б відповідь.
`trBare()` зрізає артикль регуляркою `ARTS` і повертає «акті».

**Посилання на відео — це пошук.** `https://www.youtube.com/results?search_query=…`
замість прямих ID: конкретні відео зникають і перезаливаються, а пошук за назвою
каналу й темою працює завжди. Канали в `videos.js` справжні (DW, Easy German,
Learn German with Anja, Deutsch mit Marija, 24h Deutsch, Slow German, Deutsch mit
Benjamin, Deutsch mit Rieke).
